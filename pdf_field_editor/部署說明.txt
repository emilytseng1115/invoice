發票 PDF／Word 處理平台
========================

使用方式
--------
1. 將整個資料夾解壓縮到電腦。
2. 確認電腦已安裝 Python 3.13（Windows 64-bit），並在安裝時勾選 Add python.exe to PATH。
3. 雙擊「一鍵安裝與啟動.bat」。
4. 第一次執行會建立獨立環境並下載必要套件，需要網路連線。
5. 安裝完成後，瀏覽器會自動開啟 http://localhost:8501/。

之後啟動
--------
直接再次雙擊「一鍵安裝與啟動.bat」，不需要重新安裝套件。

OCR 設定
--------
部署包不包含 OCR API Key，以免金鑰外洩。
需要 OCR 時，可在平台畫面的 OCR API Key 欄位輸入。
若要自動載入，可將 ocr_api_key.example.txt 複製為 ocr_api_key.txt，
再把 API Key 寫入該檔案。請勿將 ocr_api_key.txt 分享給其他人。

關閉平台
--------
關閉執行程式的黑色命令視窗，或在該視窗按 Ctrl+C。

疑難排解
--------
若視窗顯示錯誤，請查看同一資料夾內的 launcher.log。

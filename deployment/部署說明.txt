ECS 發票處理工具部署包
======================

安裝檔：dist\ECS_Invoice_Tool_Setup.exe

目標環境：Windows 10/11 64-bit，使用者端不需要安裝 Python。

安裝方式：
1. 將 ECS_Invoice_Tool_Setup.exe 複製到使用者電腦。
2. 雙擊執行。
3. 程式會安裝到使用者的 LocalAppData，不需要系統管理員權限。
4. 安裝完成後會建立「ECS 發票處理工具」桌面捷徑並自動啟動。

內含環境：
- Python 3.14.4 64-bit runtime
- Streamlit 1.57.0
- pdfplumber 0.11.10
- pypdf 6.16.2
- reportlab 4.5.1
- requests 2.33.1
- pypdfium2 5.13.0
- python-docx 1.2.0
- Pillow 12.2.0

網路需求：
- SQL API：srm.ecs.com.tw:8017
- OCR API（使用 OCR 時）：ds.ecs.com.tw:443

注意：
- OCR API Key 未內建在安裝包中，需由使用者於畫面輸入或由 IT 另行配置。
- 此測試安裝包未使用程式碼簽章憑證，Windows SmartScreen 可能顯示未知發行者警告。

ECS Invoice Tool
================

1. Double-click the desktop shortcut named ECS 發票處理工具.
2. The tool starts locally and opens the default browser automatically.
3. Upload a PDF or Word document to begin.

Notes:
- SQL Description lookup requires access to the internal SQL API.
- OCR requires access to the internal OCR API and a valid API key.
- The web service listens only on 127.0.0.1.
- Runtime errors are written to logs\streamlit.log.
